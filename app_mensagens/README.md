# Aplicativo de Mensagens com Tela de Login

Este é um aplicativo desktop completo desenvolvido em **Python com PyQt5**, contendo um sistema de **Login** e uma interface de **Chat/Mensagens** em tempo real simulado.

## 🚀 Como Executar

1. Certifique-se de ter o Python instalado.
2. Instale as dependências executando o comando abaixo no terminal:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute o aplicativo:
   ```bash
   python main.py
   ```

## 🛠️ Funcionalidades
- **Tela de Login**: Validação simples de usuário e senha.
- **Interface de Chat**: 
  - Lista de canais/conversas laterais.
  - Display de mensagens com identificação de remetente.
  - Campo de envio de mensagens com suporte à tecla `Enter`.
- **Navegação Fluida**: Alternância dinâmica entre a tela de login e o chat, com botão de logout.
